Instalação do Node.js

O Node.js é uma plataforma JavaScript que nos permite executar código JavaScript fora do navegador. Siga as instruções abaixo para instalá-lo em seu sistema:

Windows
  1. Visite o site oficial do Node.js
  2. Baixe a versão LTS (Long Term Support) recomendada para a maioria dos usuários
  3. Execute o instalador baixado e siga as instruções na tela
  4. Por padrão, o instalador adicionará o Node.js ao PATH do sistema
  5. Após a instalação, reinicie o computador para garantir que as mudanças entrem em vigor
macOS
Opção 1: Instalação direta
  1. Visite o site oficial do Node.js
  2. Baixe a versão LTS (Long Term Support) para macOS
  3. Execute o pacote .pkg baixado e siga as instruções na tela
Opção 2: Usando Homebrew (recomendado se você já tem o Homebrew)
  1. Abra o Terminal
  2. Execute o seguinte comando para instalar o Node.js: 
    brew install node
Linux
Ubuntu, Debian e distribuições baseadas:
  1. Abra o Terminal
  2. Atualize o índice do pacote e instale as dependências: 
    sudo apt update
sudo apt install -y curl
  3. Adicione o PPA NodeSource (para versão LTS): 
    curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
  4. Instale o Node.js: 
    sudo apt install -y nodejs
Fedora, CentOS e RHEL:
  1. Abra o Terminal
  2. Adicione o repositório NodeSource: 
    curl -fsSL https://rpm.nodesource.com/setup_lts.x | sudo bash -
  3. Instale o Node.js: 
    sudo yum install -y nodejs

Instalação do Git

O Git é um sistema de controle de versão distribuído que usaremos para gerenciar nosso código. Siga as instruções para instalá-lo:

Windows
  1. Visite o site oficial do Git para Windows
  2. Baixe o instalador do Git
  3. Execute o instalador e siga estas recomendações:
    • Use Git from the Windows Command Prompt (opção padrão)
    • Use OpenSSL para HTTPS (opção padrão)
    • Checkout Windows-style, commit Unix-style line endings (opção padrão)
    • Use MinTTY (opção padrão)
    • Habilite o cache de credenciais
  4. Conclua a instalação seguindo as demais instruções
macOS
Opção 1: Instalar com Homebrew (Recomendado)
  1. Abra o Terminal
  2. Execute o seguinte comando: 
    brew install git
Opção 2: Baixar o Instalador
  1. Visite git-scm.com
  2. Baixe e execute o instalador do macOS
  3. Siga as instruções na tela para concluir a instalação
Linux
Ubuntu, Debian e distribuições baseadas:
  1. Abra o Terminal
  2. Atualize os pacotes: 
    sudo apt update
  3. Instale o Git: 
    sudo apt install git
Fedora:
  1. Abra o Terminal
  2. Instale o Git: 
    sudo dnf install git
Arch Linux:
  1. Abra o Terminal
  2. Instale o Git: 
    sudo pacman -S git

Verificação de Instalações

Após instalar o Node.js e o Git, verifique se eles foram instalados corretamente executando os seguintes comandos no terminal:

Terminal / Prompt de Comando
# Verificar versão do Node.js
node -v

# Verificar versão do npm
npm -v

# Verificar versão do git
git --version
Verificação bem-sucedida

Se você visualizar as versões instaladas (por exemplo, v16.14.0, 8.3.1, 2.35.1), então você configurou seu ambiente corretamente e está pronto para começar!

Organizando seu Código: HTML, CSS e JavaScript

Separação de Arquivos: O Padrão da Indústria

É possível incluir JavaScript e CSS diretamente dentro do arquivo HTML, mas o padrão de mercado é manter esses códigos em arquivos separados. Vejamos as diferentes abordagens e por que a separação é considerada a melhor prática:

Aspecto Código Interno (Embutido) Arquivos Separados
Organização Todo o código em um único arquivo Cada tecnologia tem seu próprio arquivo (HTML, CSS, JS)
Manutenção Mais difícil de manter em projetos grandes Facilita a manutenção e leitura do código
Cache do navegador Não permite cache eficiente Permite que o navegador armazene em cache arquivos separadamente
Reutilização Difícil reutilizar código entre páginas Mesmo arquivo pode ser usado em múltiplas páginas
Colaboração Dificulta trabalho em equipe Permite que diferentes desenvolvedores trabalhem em partes específicas

Como Vincular Arquivos Externos

Para criar uma estrutura de projeto organizada, você deve separar seu código em arquivos distintos e vinculá-los ao HTML principal:

Vinculando um arquivo CSS externo
HTML (index.html)
<!DOCTYPE html>
<html>
<head>
    <title>Meu Projeto</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <h1>Minha Página</h1>
</body>
</html>
CSS (styles.css)
body {
    font-family: Arial, sans-serif;
    background-color: #f0f0f0;
}

h1 {
    color: #333;
    text-align: center;
}
Vinculando um arquivo JavaScript externo
HTML (index.html)
<!DOCTYPE html>
<html>
<head>
    <title>Meu Projeto</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <h1>Minha Página</h1>
    
    <!-- Script no final do body para melhor performance -->
    <script src="script.js"></script>
</body>
</html>
JavaScript (script.js)
// Este código será executado quando a página carregar
console.log("Página carregada!");

// Função que pode ser chamada de qualquer lugar
function saudacao() {
    alert("Olá, bem-vindo à página!");
}

Estrutura de Projeto Recomendada

Uma estrutura de projeto organizada melhora significativamente a manutenção e escalabilidade:

Estrutura de Diretórios
projeto/
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── script.js
│   └── images/
│       └── logo.png
└── pages/
    ├── about.html
    └── contact.html
Benefícios do Padrão de Mercado
  • Separação de Responsabilidades: Cada arquivo tem um propósito específico, seguindo o princípio da "Separação de Responsabilidades" (HTML = estrutura, CSS = apresentação, JS = comportamento)
  • Performance: Arquivos separados podem ser carregados em paralelo e armazenados em cache pelo navegador
  • Manutenção: Facilita encontrar e corrigir problemas
  • Escalabilidade: Projeto pode crescer de forma organizada
  • Colaboração: Equipes podem trabalhar simultaneamente em diferentes partes do código
  • Reutilização: Os mesmos arquivos CSS e JS podem ser compartilhados entre várias páginas HTML
