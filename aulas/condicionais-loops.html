1. Operadores Lógicos e Comparações

Antes de aprender condicionais, é essencial dominar os operadores que permitem fazer comparações e combinar condições.

Operadores de Comparação

Operadores básicos
let a = 5, b = 10;

console.log(a == b);   // false (igualdade)
console.log(a === b);  // false (igualdade estrita)
console.log(a != b);   // true (diferente)
console.log(a !== b);  // true (diferente estrito)
console.log(a < b);    // true (menor que)
console.log(a > b);    // false (maior que)
console.log(a <= b);   // true (menor ou igual)
console.log(a >= b);   // false (maior ou igual)

Operadores Lógicos

AND, OR e NOT
let idade = 25;
let temCarteira = true;

// AND (&&) - ambas condições devem ser verdadeiras
if (idade >= 18 && temCarteira) {
  console.log("Pode dirigir");
}

// OR (||) - pelo menos uma condição deve ser verdadeira
if (idade < 18 || !temCarteira) {
  console.log("Não pode dirigir");
}

// NOT (!) - inverte o valor booleano
if (!temCarteira) {
  console.log("Precisa de carteira");
}
Dica: Use === e !== em vez de == e != para comparações mais seguras que verificam tipo e valor.

2. Estruturas Condicionais (if / else)

As estruturas condicionais permitem que o programa execute diferentes blocos de código de acordo com condições específicas.

Exemplo simples de if
let tarefaConcluida = true;

if (tarefaConcluida) {
  console.log("A tarefa está concluída!");
}
Exemplo if / else
let prioridade = 2; // 1: baixa, 2: média, 3: alta

if (prioridade === 3) {
  console.log("Prioridade Alta");
} else {
  console.log("Prioridade não é alta");
}
Exemplo if / else if / else
if (prioridade === 1) {
  console.log("Prioridade Baixa");
} else if (prioridade === 2) {
  console.log("Prioridade Média");
} else if (prioridade === 3) {
  console.log("Prioridade Alta");
} else {
  console.log("Prioridade desconhecida");
}

Também é possível aninhar condicionais dentro de outras, embora seja recomendável manter o código claro para facilitar a manutenção.

3. Switch Case

A estrutura switch é útil quando há muitas comparações sobre uma mesma variável.

Exemplo de switch
let diaSemana = new Date().getDay(); // 0: Domingo, 1: Segunda, etc.

switch (diaSemana) {
  case 0:
    console.log("Domingo");
    break;
  case 1:
    console.log("Segunda-feira");
    break;
  // ...
  default:
    console.log("Dia inválido");
    break;
}

O uso de break é essencial para evitar que a execução "pule" para o próximo caso. Em alguns cenários, porém, aproveita-se a ausência de break para agrupar comportamentos semelhantes (conhecido como fall-through).

4. Loops (for, while, do/while)

Loops (estruturas de repetição) permitem executar um bloco de código múltiplas vezes, de acordo com uma condição ou até esgotar um conjunto de dados.

for

for (let i = 0; i < 5; i++) {
  console.log("Contagem:", i);
}

No loop for, temos três partes entre parênteses: inicialização (let i = 0), condição (i < 5) e incremento (i++).

while

let contador = 0;
while (contador < 5) {
  console.log("Contagem:", contador);
  contador++;
}

O while executa o bloco enquanto a condição (no caso, contador < 5) for verdadeira.

do/while

let numero = 5;
do {
  console.log("Número é:", numero);
  numero--;
} while (numero > 0);

Ao contrário do while, o do/while executa o bloco ao menos uma vez antes de verificar a condição.

Loops Avançados

for...in (itera sobre propriedades)
let pessoa = { nome: "João", idade: 30, cidade: "São Paulo" };

for (let propriedade in pessoa) {
  console.log(propriedade + ": " + pessoa[propriedade]);
}
// nome: João
// idade: 30
// cidade: São Paulo
for...of (itera sobre valores)
let frutas = ["maçã", "banana", "laranja"];

for (let fruta of frutas) {
  console.log(fruta);
}
// maçã
// banana
// laranja
break e continue
// break - sai do loop completamente
for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i); // 0, 1, 2, 3, 4
}

// continue - pula para a próxima iteração
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) continue;
  console.log(i); // 1, 3, 5, 7, 9 (apenas ímpares)
}

5. Exercícios Práticos

Exercício 1: Condicional de Acesso

Crie uma variável nivelAcesso (1, 2 ou 3). Se o acesso for 3, exiba "Acesso Total"; se for 2, exiba "Acesso Parcial"; senão, exiba "Acesso Negado".

Ver solução
Exemplo de Resolução
let nivelAcesso = 2;

if (nivelAcesso === 3) {
  console.log("Acesso Total");
} else if (nivelAcesso === 2) {
  console.log("Acesso Parcial");
} else {
  console.log("Acesso Negado");
}

Exercício 2: Avaliação de Notas

Crie uma variável nota. Use o switch para avaliar:

  • Se 10, exiba "Nota Máxima".
  • Se 8 ou 9, exiba "Muito Bom".
  • Se 6 ou 7, exiba "Bom".
  • Se 5, exiba "Regular".
  • Caso contrário, exiba "Nota insuficiente".
Ver solução
Exemplo de Resolução
let nota = 8;
switch (nota) {
  case 10:
    console.log("Nota Máxima");
    break;
  case 9:
  case 8:
    console.log("Muito Bom");
    break;
  case 7:
  case 6:
    console.log("Bom");
    break;
  case 5:
    console.log("Regular");
    break;
  default:
    console.log("Nota insuficiente");
    break;
}

Exercício 3: Listando Números Pares

Use um for para exibir apenas os números pares de 1 a 10 no console.

Ver solução
Exemplo de Resolução
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) {
    console.log("Par:", i);
  }
}

Exercício 4: Soma com while

Usando um while, some todos os números de 1 a 5 e exiba o resultado.

Ver solução
Exemplo de Resolução
let soma = 0;
let contador = 1;
while (contador <= 5) {
  soma += contador;
  contador++;
}
console.log("Soma total:", soma); // 15

Exercício 5: do/while de Contagem Regressiva

Crie uma contagem regressiva usando do/while que inicie em 3 e vá até 1, exibindo "FIM!" ao término.

Ver solução
Exemplo de Resolução
let n = 3;
do {
  console.log(n);
  n--;
} while (n > 0);
console.log("FIM!");

Exercício 6: Calculadora Simples

Peça ao usuário dois valores (prompt() ou atribuições diretas) e um operador (+, -, *, /). Use switch para realizar a operação e exibir o resultado.

Ver solução
Exemplo de Resolução
let valor1 = 10; // fazendo a associação direta
let valor2 = 2;  // fazendo a associação direta
let operador = "*"; // fazendo a associação direta

//Ou peça para o usuário digitar os valores utilizando o prompt
//Só que nesse caso você precisa converter o retorno do prompt dos valores 1 e 2 para Number.

let valor1 = Number(prompt("Digite o primeiro valor"));
let valor2 = Number(prompt("Digite o segundo valor"));
let operador = prompt("Digite o operador (+, -, *, /)");

switch (operador) {
  case "+":
    console.log(valor1 + valor2);
    break;
  case "-":
    console.log(valor1 - valor2);
    break;
  case "*":
    console.log(valor1 * valor2);
    break;
  case "/":
    console.log(valor1 / valor2);
    break;
  default:
    console.log("Operador inválido");
}

Exercício 7: Sistema de Notas Escolares

Crie um sistema que receba uma nota (0-10) e calcule a média de 3 notas. Use condicionais para determinar o conceito:

  • A (9-10): Excelente
  • B (7-8.9): Bom
  • C (5-6.9): Regular
  • D (3-4.9): Insuficiente
  • F (0-2.9): Reprovado
Ver solução
Exemplo de Resolução
let nota1 = 8.5;
let nota2 = 7.0;
let nota3 = 9.2;

let media = (nota1 + nota2 + nota3) / 3;

console.log("Média:", media.toFixed(1));

if (media >= 9) {
  console.log("Conceito: A - Excelente");
} else if (media >= 7) {
  console.log("Conceito: B - Bom");
} else if (media >= 5) {
  console.log("Conceito: C - Regular");
} else if (media >= 3) {
  console.log("Conceito: D - Insuficiente");
} else {
  console.log("Conceito: F - Reprovado");
}

Exercício 8: Tabuada Interativa

Crie um programa que gere a tabuada de um número usando diferentes tipos de loops. Compare os resultados.

Ver solução
Exemplo de Resolução
let numero = 7;

console.log("Tabuada do " + numero + " (usando for):");
for (let i = 1; i <= 10; i++) {
  console.log(numero + " x " + i + " = " + (numero * i));
}

console.log("\nTabuada do " + numero + " (usando while):");
let contador = 1;
while (contador <= 10) {
  console.log(numero + " x " + contador + " = " + (numero * contador));
  contador++;
}
