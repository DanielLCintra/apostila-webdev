Questão 1 – Condicional If

  1. Crie uma variável chamada tarefaConcluida e atribua a ela qualquer valor (por exemplo: true, false, null, "sim", etc.).
  2. Utilize uma estrutura if / else para verificar o valor da variável:
    • Se for exatamente true, exiba no console: "A tarefa está concluída!"
    • Caso contrário, exiba: "A tarefa não foi concluída."

Questão 2 – Condicional If/Else If/Else

  1. Crie uma variável prioridade com um valor numérico (1, 2 ou 3).
  2. Utilize uma estrutura if/else if/else para exibir:
    • "Prioridade Baixa" se o valor for 1;
    • "Prioridade Média" se o valor for 2;
    • "Prioridade Alta" se o valor for 3.

Questão 3 – Switch Case

  1. Crie uma variável diaSemana que receba o valor retornado por new Date().getDay().
  2. Utilize a estrutura switch para exibir o nome do dia correspondente (0 para "Domingo", 1 para "Segunda-feira", etc.), utilizando break em cada caso.

Questão 4 – Loop For

  1. Crie um loop for que exiba os números de 0 a 9 no console.

Questão 5 – Loop While

  1. Utilize um loop while para somar os números de 1 a 5 e exiba a soma total no console.

Questão 6 – Loop do/while

  1. Crie uma contagem regressiva usando do/while que inicie em 3 e vá até 1, e que, ao final, exiba "FIM!" no console.

Questão 7 – Verificador de Idade

  1. Em script.js, crie uma função chamada verificarIdade(idade) que retorne:
    • "Menor de idade" se idade < 18;
    • "Maior de idade" se idade >= 18 && idade < 60;
    • "Idoso" se idade >= 60.
  2. Teste a função com diferentes idades e exiba os resultados no console.

Questão 8 – Acesso ao Sistema

  1. Em script.js, crie duas variáveis:
    • temSenhaCorreta (valor booleano);
    • temBiometriaAutenticada (valor booleano);
  2. Crie uma variável chamada acessoPermitido que será true se:
    • O usuário tiver a senha correta OU a biometria autenticada.
  3. Exiba no console:
    • O valor de acessoPermitido;
    • O valor inverso (com !) de acessoPermitido, indicando se o acesso foi negado.

Questão 9 – Manipulação de Strings

  1. Crie uma string contendo várias tarefas separadas por vírgula.
  2. Transforme essa string em um array usando split() e depois em uma string formatada com join(" | ").
  3. Verifique se a palavra "Estudar" está presente utilizando includes().
  4. Exiba todos os resultados no console.

Questão 10 – Números Aleatórios e Área de Círculo

  1. Crie uma função que gere um número aleatório entre 5 e 15.
  2. Com esse número como raio, calcule a área de um círculo e exiba o resultado com duas casas decimais no console.
  3. Dica: utilize Math.random(), Math.PI, Math.pow() e toFixed().
